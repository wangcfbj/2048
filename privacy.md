# Privacy Policy / 隐私权政策

Last updated / 更新日期: 2026-09-28

**English**

- 2048 Game v2 does not collect, transmit, or sell any personal data.
- Game progress, best score, and history are stored only on your device via `chrome.storage.local`.
- The extension makes no network requests and uses no analytics or third-party services.
- You can remove all stored data at any time by uninstalling the extension.

**中文**

- 2048 Game v2 不收集、不上传、不出售任何个人数据。
- 游戏进度、最高分和历史记录仅通过 `chrome.storage.local` 保存在您的本地设备上。
- 本扩展不发起任何网络请求，不使用任何统计分析或第三方服务。
- 卸载扩展即可清除所有已保存的数据。
